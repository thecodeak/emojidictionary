# Emoji Dictionary

> 🗄️ **Archived learning project.** Built in 2017 while taking an introductory iOS course, kept as-is as a snapshot of where I started. It targets Swift 3 / iOS 10 and won't build in current Xcode without migration.

A table of emojis. Tap one and a second screen shows its "definition".

**What I learned:** `UITableView` data source and delegate, segues, and passing data between view controllers in `prepare(for:sender:)`.

**Stack:** Swift 3 · UIKit · Storyboards

> Note: only the source files (Swift, storyboards, assets) were committed. The `.xcodeproj` is missing, so this can't be opened as a project.
